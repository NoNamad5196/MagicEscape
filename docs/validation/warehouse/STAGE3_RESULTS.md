# 창고 3단계 — 치우기 / 원소 기호 / 원소표 검증

## 변경 내용
- PC와 VR이 같은 XRI 인터랙터블을 사용하는 상자 밀기·끌기, 천 걷기, 책 더미 Grab, 궤짝 경첩 열기를 추가했다. HandlingProfile의 Lift / PushPull / Fixed 데이터를 실제 동작에 연결했다.
- I·IV 액자는 각각 상자를 옆으로 옮겨야 조사된다. 궤짝을 열어야 수정 가루를 얻는다. 책 아래에는 원소표 낱장이 있다.
- ClearingGate가 숨긴 대상의 콜라이더와 XRI를 비활성화하고 직접 조사·픽업·인벤토리 어댑터 호출도 차단한다. 치우기는 퍼즐 상태를 바꾸지 않는다.
- 액자 모서리 기호는 문양석과 같은 FGlyph 황동 재질/도안을 사용한다. 표시 폭 .31 → .40, 기호 선 7 → 11px. 대지·바람의 가로줄을 강조했다.
- III 그림은 갈라진 땅·시든 잎·아지랑이·강한 해로 IV의 꽃과 구분했다. 세피아/해칭 톤을 유지했다.
- 천 아래 벽걸이 양피지에는 글자·번호·화살표 없이 여섯 기호와 대응 그림을 넣었다. 클릭/E 확대를 지원한다. 정답 순서는 액자의 I~IV만 사용한다.
- RuneId, 아이템 ID, 대지 → 물 → 불 → 빛, P1 → P2 → P3는 유지했다. AGENTS.md / WAREHOUSE_XRI.md / README를 갱신했다.

## 실제 검증
Unity 6000.3.28f1, Windows batchmode. Unity는 한 번에 하나만 실행했다.

| 검증 | 통과 | 실패 | 로컬 원본 증거 |
|---|---:|---:|---|
| Warehouse 씬 전체 재생성 | 종료 0 | — | stage3-accept-generate.log |
| EditMode 전체 | 7 | 0 | stage3-final-editmode.xml |
| PlayMode 전체: 기존 회귀 + 창고 | 32 | 0 | stage3-final-playmode.xml |
| 순수 C# | 44 | 0 | stage3-accept-core.trx |

- 최종 Unity 테스트는 커밋 대상이 아닌 Classroom/공유 에셋 재생성 차이를 HEAD로 잠시 되돌린 상태에서도 전부 통과했다. 기존 작업 파일은 별도로 보존한 뒤 복원했다. 관계없는 재생성 변경은 이번 커밋에 넣지 않았다.
- 실행 결과의 환경 정보 없는 요약, 개별 테스트 이름, 캡처 SHA-256은 [stage3-final-summary.json](stage3-final-summary.json)에 있다. 원본 XML/TRX/로그는 로컬에 남기고 커밋하지 않는다.
- PC 입력 테스트: 좌클릭 유지 + 이동으로 상자 옮기기, E로 천 걷기, 클릭으로 궤짝 열기, 책을 카메라 앞에 들어 옮기기와 지지면 위 내려놓기를 확인했다.
- 숨긴 대상의 콜라이더/XRI/직접 조사 차단과 수정 가루 획득 차단, 상자 재배치 시 단서 재차단을 확인했다.
- 상자 이동 극단값에서도 바닥 높이·벽 안쪽·서쪽 수납 구역을 유지하며 출구/소켓을 막지 않는 검사를 통과했다.
- 치우기 → P1 → P2 → P3 → 문 열림 → W 이동으로 출구 통과까지 통과했다. 기존 액자/상자 지지·부착 검사와 새 상자·책·천·뚜껑 지지/동적 계층 검사를 통과했다.
- 시뮬레이션된 VR 컨트롤러로 같은 상자를 잡아 끌고 비선택 손 접촉으로 미는 검사도 통과했다. 실제 HMD 검증은 아니다.
- CodeDrafts와 Unity Runtime 미러의 텍스트 일치를 검사했다.
- 작업 진입 시 존재하던 미추적 XML/TRX 31개는 SHA-256 비교로 모두 무변경을 확인했고 스테이징하지 않았다.

## 판단한 것
- **PC 끌기:** 좌클릭을 누른 채 WASD로 움직인다. 마우스 회전만으로도 카메라 앞 부착점 변위가 전달된다. 놓으면 XRI 선택이 끝나고 멈춘다. 무거운 상자는 Y축으로 들리지 않는다.
- **막힘 방지:** 자유 물리 시뮬레이션 대신 서쪽 벽의 독립 Z축 레일, 고정 X/바닥 Y를 사용했다. 두 상자·벽·남쪽 궤짝과 적재물·제단·가마솥·소켓·출구가 겹치지 않는 범위다. 투척/중력 속도를 만들지 않는다. ResetProp 복구 경로도 제공한다. 책은 놓을 때 옆 상자의 지지면으로 주차한다.
- **원소표 위치:** 제단 가까운 서쪽 벽 (-4.35, 1.6, .65). 목재 걸이와 고정끈에 매달고 천으로 가렸다. 여섯 원소는 정답과 다른 순서로 배치하고 순서 표시는 넣지 않았다.

## 남은 문제 / 범위 밖
- 자동 테스트에서 확인된 미해결 실패는 없다. 실제 HMD의 손 접촉 감각·조작성·편안함과 수동 전체 VR 플레이는 미검증이다.
- Editor 로그에는 라이선스 access-token 갱신 경고와 HMD 없는 OpenXR Display 초기화 실패가 남는다. 종료 코드와 테스트 결과는 정상이며, 데스크톱 fallback / 합성 컨트롤러 검사는 통과했다.
- 4단계 어두워짐 강화와 S11/standalone 빌드는 실행하지 않았다. Notion은 이번 작업에서 갱신하지 않았다.
